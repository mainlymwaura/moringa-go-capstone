# Prompt-Powered Kickstart: Getting Started with Go (Golang)

## 1. Title & Objective

**Technology chosen:** Go 1.22 (Golang)

**Why Go?** 
- Simple syntax with only 25 keywords
- One binary install, no dependencies
- Used by Docker, Kubernetes, Terraform

**End goal:** Run a working Go program that prints output and uses a custom function

## 2. Quick Summary of the Technology

**What is Go?** A statically typed, compiled programming language designed at Google for building fast, reliable, and simple software.

**Where is it used?**
- Backend web servers (Uber, Dropbox)
- Cloud tools (Docker, Kubernetes)
- CLI applications (GitHub CLI)

**Real-world example:** Docker (container platform) is written entirely in Go.

## 3. System Requirements

| Requirement | Specification |
|-------------|---------------|
| OS | Windows 10+, macOS 11+, or Linux |
| Disk space | ~250 MB for Go installation |
| RAM | 4GB minimum (any modern computer) |
| Editor | VS Code (free) or any text editor |
| Terminal | Command Prompt (Win) / Terminal (Mac/Linux) |
